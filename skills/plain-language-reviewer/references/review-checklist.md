# The review checklist and the word list

Work through this for any H&S document before it is issued. Every **no** needs either a change or
a written reason no change is needed — recording the reason is what stops the same argument
recurring at the next review.

> Structured after the checklist in the WorkSafe NZ GPG *Writing for health and safety* (Nov 2017);
> wording and the word list below are original. **Sources last verified: 2026-09-04.**

## 1. Purpose

- [ ] Is it clear **what the document is for**?
- [ ] Is it clear **who needs to read it**?
- [ ] Is it clear **when** they read it — at induction, daily at the workface, or in an emergency?
- [ ] Is it the **right form** for that job (procedure, flowchart, table, sign, one-page summary)?
- [ ] Is it **as short as the risk allows**?

## 2. Worker input

- [ ] Were workers asked **what should be in it** and **how it should look**, before drafting?
- [ ] Have you discussed with workers what they **like** and **do not like** about it?
- [ ] Have workers confirmed it **covers what they need to know**?
- [ ] Have you told workers **where their feedback was used**, and **why** any was not?
- [ ] If naming contributors would increase trust, have you named them **with their permission**?

## 3. Testing and feedback

- [ ] Tested with the **people who will actually use it** — frontline workers, not just managers?
- [ ] Tested with **supervisors**, **H&S representatives**, and **union representatives** where
      relevant, or the H&S committee?
- [ ] Have **managers** reviewed and commented?
- [ ] Has a **comprehension check** been run (demonstration or thinking aloud), not just a read-and-
      sign? See `comprehension-testing.md`.
- [ ] Has **all feedback been considered** and the required changes made?

## 4. Accuracy

The block that generic writing guidance never has, and the one that matters most. Is the document
accurate against:

- [ ] your **workplace H&S system** — does it describe what actually happens here?
- [ ] the governing **Act** (NZ **HSWA 2015** / the applicable **AU WHS Act**, or Victoria's **OHS
      Act 2004**)?
- [ ] the **regulations** that apply to this workplace?
- [ ] the relevant **ACOPs, good practice guidelines or Codes of Practice**?
- [ ] **industry standards, guidelines and manuals** — including the **manufacturer's** instructions
      for the plant involved?
- [ ] the **work risks and the controls** that manage them — and are those controls named
      specifically rather than gestured at?
- [ ] the **activities and tasks** as they are actually carried out?

**Accuracy outranks readability.** If a simplification changes what a duty or a control requires,
revert it and find another way to make it clear. A clear document that says the wrong thing is more
dangerous than an unread one that says the right thing.

## 5. Layout and language

- [ ] Is it clear which parts are **instructions** and which are **information**?
- [ ] Does each instruction start with a **verb**, and are steps **numbered in order**?
- [ ] **Simple everyday words**, especially where a technical term is explained?
- [ ] Is each technical term **explained in plain English before the term is introduced**?
- [ ] **Examples** used to explain difficult ideas or processes?
- [ ] Every **acronym and abbreviation expanded on first use** — and the unnecessary ones removed?
- [ ] **Short sentences** — one or two ideas each?
- [ ] **Active voice** with a named actor?
- [ ] **Short paragraphs**, one main message each?
- [ ] **Bullets or simple tables** for key points?
- [ ] A **clear logical order**?
- [ ] **Subheadings** so readers can find what they need?
- [ ] A **plain font** (Arial, Calibri, Verdana), used consistently?
- [ ] **Different font sizes** for headings and subheadings?
- [ ] **Bold** for emphasis — not underlining, not blocks of capitals?
- [ ] **Plenty of line spacing and white space**?
- [ ] **Relevant, clearly labelled visuals** — photographs, diagrams, graphs?
- [ ] **Limited colour**, and does it still work photocopied in black and white?
- [ ] Are **alternate formats** needed for any reader (audio, large print, braille, captioned
      video)?

## 6. Quality control

- [ ] Has **more than one person** checked it for spelling and other errors?
- [ ] Has someone who **has not seen it before** proofread the final draft?
- [ ] Followed your workplace's processes for **quality assurance, document checking, version
      control and approval**?
- [ ] Does it carry a **version number and date**, so the wrong copy is identifiable?
- [ ] Is the **next review date** set, and is there a trigger to review it early (change of plant,
      process, people, or law)?
- [ ] Is there a plan for **how it will be shared, who introduces it, and how workers are trained
      in it**?
- [ ] Is there a way to know **whether it is actually being used** — and used the way you expected?

### Vague words that hide a missing control

These are not style problems. Each one usually means the control has not been decided. Flag every
instance and send it back to the author or the hazard SME.

| Vague | The question it dodges |
|---|---|
| appropriate / suitable / adequate | Which one, exactly? Name the item, class or rating. |
| as necessary / where required / if practicable | Decided by whom, on what basis? |
| be careful / take care / exercise caution | Do what, specifically? |
| regularly / periodically / from time to time | How often? |
| competent / trained / authorised person | Trained in what, evidenced how? |
| relevant PPE / correct PPE | Which items, to which standard? |
| safe distance / clear of | How far? |
| where possible / wherever practicable | If it is possible here, say so; if not, say what happens instead. |
| ensure safety | The whole document is meant to answer this. |
